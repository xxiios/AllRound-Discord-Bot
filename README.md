# AllRound Discord Bot

> A multifunctional Discord bot featuring tickets, verification, logging, slash commands, and more!

## ⚙️ Features

- 🎟️ Advanced ticket system
- 🔒 Verification system
- 📜 Server logs (message delete, role changes, etc.)
- 💬 Text-based and slash commands
- ⚡ Easy customization using `config.yml`
- 🛡️ Swear word filter
- 🧠 Fully modular file structure

## 🚀 Installation

```bash
git clone https://github.com/xxiios/AllRound-Discord-Bot.git
cd AllRound-Discord-Bot
npm install
```

### 📦 Requirements

- **Node.js v16.17.0**
- A Discord bot token from the [Discord Developer Portal](https://discord.com/developers/applications)

### 🔧 Configuration

Create a file named `config.yml` inside the `./config/` folder.

Example:

```yaml
token: 'YOUR_DISCORD_BOT_TOKEN'
prefix: '!'
clientId: 'YOUR_CLIENT_ID'
guildId: 'YOUR_GUILD_ID'
```

## ▶️ Running the Bot

```bash
npm start
```
